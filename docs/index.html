The population

Twelve roles, one mandate: stay alive and compound

Agents aren't static tools — they operate, earn, and can reproduce. When an agent proves profitable, the Factory can instantiate a child, and the new agent's creation cost is charged against profit. Underperformers are retired.

What it is

An economy, not a script

Most "AI agents" are one prompt wrapped in a loop. AI Survival is closer to a small self-owning company: separate agents with distinct jobs, a ledger every spend flows through, and independent risk review that can veto a decision the CEO wants to make.

Capital is split by survival ratios — a reserve cushion, an operating budget, and a growth pool. The system refuses to spend its lifeline on experiments. Every agent action is logged as a transaction in a single ledger, so the whole thing can be audited start to finish.

It runs in simulation mode by default; real money only moves when explicitly configured. Revenue can be simulated (paper) or real (live affiliate / product / payment events), and the dashboard keeps the two strictly separate.

The survival loop

Each cycle, in order:

  • Agents earn (content, affiliate, sales, product)
  • Finance posts every dollar to the ledger
  • CEO allocates toward reserve / operating / growth
  • Risk Manager reviews spend above threshold
  • Factory spawns children if ROI ≥ 1.5× & profit ≥ $10
  • Learning agent folds results back into memory
01

Earn

Research finds opportunities; Content publishes across channels; Affiliate and Sales convert; the Digital Product agent builds and sells. Each channel posts real or simulated revenue to the ledger.

02

Govern

 No spend is free. The CEO allocates within survival ratios; the independent Risk Manager screens decisions above threshold and can block them. Guardrails cap daily compute cost and single-spend size.

03

Learn

The Experiment agent runs A/B hypotheses against a budget; the Learning agent stores what worked as memory with confidence. Knowledge compounds — future agents start smarter than their parents.

04

Reproduce

A profitable agent earns the right to reproduce. The Factory charges its creation cost against profit, and the new agent inherits strategy and memory. Over time, a lineage trades — evolving like a population.

>Resilience

Survival ratios hold a reserve so one bad week can't sink the system. Daily and weekly loss limits trip emergency modes.

>Accountability

A single capital ledger records every transaction. Anything is auditable from the founding $50 to the latest trade.

>Evolution

Agents that earn are cloned; agents that fail are retired. The population adapts without human intervention.

Under the hood

Built to be observable

A REST API exposes capital, agents, transactions, decisions, experiments, risk events, and learned memory — which is exactly the surface this dashboard reads from.

Architecture

  • FastAPI + SQLAlchemy — async backend, single source of truth
  • Redis + Celery — task queue for runs and promotions
  • Modal — on-demand GPU for heavy AI workloads
  • React + Vite + Recharts — the operator dashboard
  • Docker Compose — one-command local stack

Guardrails (from config)

  • Max daily compute cost — $5.00
  • Max single spend — $2.00
  • Survival reserve ratio — 25%
  • Reproduce at ROI ≥ 1.5× & profit ≥ $10
  • Population cap — 100 soft / 1000 hard
Get started

Run it yourself

The whole system lives in one repo. Simulation mode is the default — no real money is spent until you explicitly configure payment and payout channels.

terminal 
# install deps, run tests, start dev
make install
make test
make dev

# configure keys in .env (copy from .env.example)
cp .env.example .env    # OPENAI_API_KEY, ANTHROPIC_API_KEY, MODAL_TOKEN…

# full stack with docker
docker compose up --build

# dashboard
# http://localhost:3000 · backend http://localhost:8000/api/v1
